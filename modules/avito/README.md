# 🛡️ Avito NoAds & Deep Filter для Shadowrocket (iOS)

## 📌 Возможности
- 🚫 **Блокировка рекламы:** баннеры, VIP, промо-карусели, рекламные аукционы — всё срезается автоматически.
- 🛑 **Блокировка трекеров:** `adriver`, `vk-analytics`, `adjust`, `buzzoola`, `stats.avito.ru`, `clickstream` и др.
- 🎯 **Фильтр по стоп-словам:** скрывает объявления по ключевым словам.
- 💰 **Фильтр по цене:** скрывает объявления дороже заданной суммы.
- 📂 **Фильтр по категориям:** стоп-слова и цена применяются только в выбранных категориях (вакансии, услуги, авто и др.).
- 🏙️ **Приоритет своего города:** автоматически ставит «Сначала из моего города» без ручного переключения.

Вставьте ссылку в **Shadowrocket** → **Modules** → **`+`**:
```text
https://raw.githubusercontent.com/bkmz735/shadowrocket-modules/main/modules/avito/avito-noads.sgmodule
```

## ⚙️ Настройка

После установки модуля в Shadowrocket → Modules → нажмите на карточку **Avito NoAds & Deep Filter**. Там 4 поля:

### `слова` — стоп-слова
Ключевые слова через `|`. Объявления с этими словами будут скрыты.
```
бпла|дрон|продам|вахта|курьер
```

### `цена` — фильтр по цене (₽)
Поддерживает любые удобные форматы:
- **Диапазон:** `от 5000 до 200000` или `5000-200000`
- **Только минимум:** `от 5000` (скроет скам за 1-100 ₽)
- **Только максимум:** `до 200000` или просто `200000`
- **Выключено:** `0` или пусто
```
5000-200000
```

### `категории` — где применять фильтры
Стоп-слова и цена работают **только** в указанных категориях. Если поле пустое — фильтры отключены (работает только блокировка рекламы).

| Название | Что фильтрует |
|---|---|
| `вакансии` | Только вакансии |
| `резюме` | Только резюме |
| `работа` | Вакансии + резюме |
| `услуги` | Услуги |
| `авто` / `машины` / `транспорт` | Транспорт |
| `недвижимость` / `квартиры` | Недвижимость |
| `электроника` / `телефоны` | Электроника |
| `все` / `all` | Везде |

Пример — фильтровать только вакансии и услуги:
```
вакансии|услуги
```

> **Регистр не важен:** `Вакансии`, `ВАКАНСИИ`, `вакансии` — одно и то же.

### `город` — приоритет своего города
- `1` — включено (каждый запрос поиска автоматически получает «Сначала из моего города»)
- `0` — выключено

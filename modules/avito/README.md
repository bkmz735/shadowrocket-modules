# 🛡️ Модуль Avito для Shadowrocket (iOS)

## 📌 Возможности
- 🚫 **Блокировка рекламы:** срезает баннеры в поисковой выдаче, карточках товаров, промо-карусели и рекламные аукционы.
- 🛑 **Блокировка трекеров:** глушит внешнюю телеметрию (`adriver`, `vk-analytics`, `uxfeedback`, `adjust`, `stats.avito.ru` и внутренний `clickstream`).
- 🎯 **Умный фильтр объявлений:** скрывает объявления и вакансии по вашим стоп-словам (например: вахта, такси, курьеры и т.д.).
- ⚙️ **Удобная настройка:** стоп-слова настраиваются прямо в карточке модуля в Shadowrocket.

---

## 🚀 Установка модуля

Вставьте эту ссылку в **Shadowrocket** → **Modules** → **`+`**:
```text
https://raw.githubusercontent.com/bkmz735/shadowrocket-modules/main/modules/avito/avito-noads.sgmodule
```

---

## ✍️ Настройка стоп-слов

1. В Shadowrocket перейдите во вкладку **Modules** → нажмите на карточку **Avito NoAds & Filter**.
2. В поле **`keywords`** впишите ваши стоп-слова через вертикальную черту `|` или через запятую (например: `такси|вахта|курьер`).
3. Нажмите **Сохранить**. Фильтр мгновенно начнет скрывать нежелательные объявления.

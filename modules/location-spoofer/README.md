# iOS Location Spoofer (Модуль Shadowrocket)

Модуль для перехвата и подмены системных координат Apple Location Services (/clls/wloc) с удобным интерфейсом на русском языке.

## Интерфейс настроек в Shadowrocket:
При открытии настроек модуля в Shadowrocket (Конфигурация -> Модули -> iOS Location Spoofer) будут доступны 3 понятных поля:

1. **город** (Пресет города):
   * Введите название города на русском (или латинице):
     * москва (или moscow)
     * питер / спб / санкт-петербург
     * киев / kiev
     * минск / minsk
     * алматы / lmaty
     * астана / stana
     * тбилиси / 	bilisi
     * ереван / yerevan
     * дубай / dubai
     * лондон / london
     * токио / 	okyo
     * купертино / pple
     * вручную (или custom) — чтобы использовать свои координаты из полей ниже.

2. **широта**:
   * Широта точки (например: 55.7558). Применяется, если в поле город указано вручную.

3. **долгота**:
   * Долгота точки (например: 37.6173). Применяется, если в поле город указано вручную.

# iOS Location Spoofer (Модуль Shadowrocket)

Модуль для перехвата и подмены системных координат Apple Location Services (/clls/wloc) в Shadowrocket с поддержкой огромной базы городов, высоты над уровнем моря и нативных push-уведомлений.

## Параметры в интерфейсе Shadowrocket:
При открытии настроек модуля (Конфигурация -> Модули -> iOS Location Spoofer) доступны параметры:

1. **город** (Пресет города):
   * Поддерживает **более 70 городов** (миллионники РФ, страны СНГ, курорты, мировые столицы). Автоматически подставляет точную широту, долготу и реальную высоту над уровнем моря.
   * *Примеры:* москва, питер, сочи, казань, екатеринбург, новосибирск, владивосток, минск, киев, алматы, астана, тбилиси, ереван, баку, ташкент, дубай, стамбул, пхукет, бали, лондон, париж, рим, нью-йорк, токио, купертино и т.д.
   * Если указать вручную (или custom) — скрипт возьмет координаты из полей ниже.
   * **Если города нет в базе:** модуль безопасно применит ручные координаты и отправит **нативное iOS Push-уведомление** с предупреждением.

2. **широта**:
   * Широта точки (например: 55.7558).

3. **долгота**:
   * Долгота точки (например: 37.6173).

4. **высота**:
   * Высота над уровнем моря в метрах (например: 156).

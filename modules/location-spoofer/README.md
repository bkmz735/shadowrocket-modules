# iOS Location Spoofer (Модуль Shadowrocket)

Модуль для перехвата и подмены системных координат Apple Location Services (/clls/wloc) с удобным интерфейсом на русском языке.

## Интерфейс настроек в Shadowrocket:
При открытии настроек модуля в Shadowrocket (Конфигурация -> Модули -> iOS Location Spoofer) доступны 4 поля:

1. **город** (Пресет города):
   * Название города (автоматически выставит широту, долготу и реальную высоту над уровнем моря):
     * москва (156 м)
     * питер / спб / санкт-петербург (11 м)
     * киев (179 м)
     * минск (220 м)
     * алматы (785 м)
     * астана (347 м)
     * тбилиси (490 м)
     * ереван (989 м)
     * дубай (5 м)
     * лондон (25 м)
     * токио (40 м)
     * купертино / pple (72 м)
     * вручную (или custom) — использовать свои значения из полей ниже.

2. **широта**:
   * Широта точки (например: 55.7558).

3. **долгота**:
   * Долгота точки (например: 37.6173).

4. **высота**:
   * Высота над уровнем моря в метрах (например: 156).

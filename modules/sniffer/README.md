# 🔍 Shadowrocket Universal Traffic Sniffer & Ad Cleaner

Универсальный набор инструментов для iOS для сниффинга трафика приложений, анализа JSON-структур ответов API и вырезания рекламы/спама через Shadowrocket.

---

## 📦 Компоненты

1. **`universal-sniffer.sgmodule`**
   - Модуль сниффинга. Подключает скрипт инспекции трафика и включает MitM (HTTPS Decryption).
   - Выводит в лог Shadowrocket подробное дерево JSON-структуры, типы элементов массивов и автоматически находит блоки рекламы.

2. **`universal_sniffer.js`**
   - JS-скрипт инспекции. Разбирает ответы API, анализирует ключи и подсвечивает рекламные метки.

3. **`universal-cleaner.sgmodule`**
   - Модуль фильтрации рекламы. Блокирует домены трекеров и пропускает ответы через скрипт очистки.
   - Поддерживает динамические аргументы ключевых слов через параметр `keywords`.

4. **`universal_cleaner.js`**
   - JS-скрипт модификации ответов. Рекурсивно удаляет элементы массивов и поля объектов, содержащие рекламу или спам.

## 🚀 Инструкция по использованию

### Шаг 1. Включение HTTPS Decryption (MitM) в Shadowrocket
1. В **Shadowrocket** перейдите в **Настройки** -> **Конфигурация**.
2. Нажмите на иконку **`(i)`** напротив активного профиля.
3. Перейдите в **HTTPS Decryption**, включите переключатель.
4. Нажмите **Generate a New CA Certificate** -> **Install CA Certificate to System**.
5. На iOS перейдите в **Настройки устройства** -> **Основные** -> **VPN и управление устройством** -> установите профиль CA.
6. Перейдите в **Настройки устройства** -> **Основные** -> **Об этом устройстве** -> **Доверие сертификатам** -> включите тумблер для сертификата Shadowrocket.

### Шаг 2. Запуск сниффинга (Инспекция трафика)
1. Скопируйте ссылку на модуль:
   `https://raw.githubusercontent.com/bkmz735/shadowrocket-modules/main/modules/sniffer/universal-sniffer.sgmodule`
2. В Shadowrocket перейдите на вкладку **Модули (Modules)** -> нажмите **`+`** -> вставьте ссылку.
3. Включите модуль.
4. Откройте нужное приложение на iOS и совершите действия (скролл ленты, поиск и т.д.).
5. Перейдите в **Shadowrocket** -> **Настройки** -> **Диагностика** -> **Логи** (или **Недавние запросы**), чтобы увидеть распарсенную структуру JSON ответов с подсказками!

### Шаг 3. Включение вырезания рекламы
1. Скопируйте ссылку на модуль очистки:
   `https://raw.githubusercontent.com/bkmz735/shadowrocket-modules/main/modules/sniffer/universal-cleaner.sgmodule`
2. Добавьте его в Shadowrocket.
3. При необходимости отредактируйте аргумент `keywords` в настройках модуля для добавления специфичных стоп-слов.

# 🎵 Spotify Premium (Shadowrocket Module)

Модуль для Shadowrocket (SR), предназначенный для разблокировки функционала Spotify Premium (неограниченные пропуски треков, выбор любого трека, разблокировка режима планшета на iPhone) и блокировки рекламных сервисов. Трафик направляется напрямую (**DIRECT**).

---

## ⚡ Быстрая установка
Скопируйте ссылку и добавьте в **Shadowrocket** -> **Modules (Модули)** -> **`+`**:
```text
https://raw.githubusercontent.com/bkmz735/shadowrocket-modules/main/modules/spotify/spotify-premium.sgmodule
```

---

## ⚙️ Особенности настройки
1. **MITM (HTTPS расшифровка)**:
   - Включите **HTTPS Decryption** в Shadowrocket.
   - Убедитесь, что CA-сертификат сгенерирован, установлен и активирован в настройках системы (*Настройки -> Основные -> Об этом устройстве -> Доверие сертификатам*).
2. **Маршрутизация трафика**:
   - Весь трафик Spotify идет напрямую (`DIRECT`) без необходимости настройки отдельных прокси-групп.
3. **Первый запуск**:
   - После включения модуля закройте приложение Spotify (выгрузите из панели многозадачности) и откройте заново.

---

## 📦 Состав модуля
- `spotify-json.js` — модификация параметров запросов клиента (подмена платформы для снятия ограничений мобильного интерфейса).
- `spotify-proto.js` — декодирование и модификация Protobuf-ответов сервера (активация статуса Premium в сессии).
